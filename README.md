# Adem Bilge — Weak Signals

An interactive field guide to Firat Adem Bilge, AI Engineer in Milan.

Live site: [adembilge.dev](https://adembilge.dev/)

Built with React, TypeScript, Vite and Lenis. Six chapters bring together experience, projects, publications, education and skills, with eight interactive figures and a printable CV view.

## Local development

Use Node.js 22 and npm.

```sh
npm ci
npm run dev
```

Full motion is enabled by default. Add `?motion=reduced` to use reduced motion.

```sh
npm test
npm run build
npm run preview
```

## Deployment

Pushing to `main` runs the tests, builds the site, and deploys `dist` to GitHub Pages through `.github/workflows/deploy.yml`. The Pages custom domain is `adembilge.dev`, with HTTPS enforced in repository settings.
